# FP-021 — Execution-Enablement Gate Failure

## Task

Investigate and record the OpenCode worker disabled-state bypass observed during SHADOW-REF-008.

## Goal

Separate a security-relevant execution-gate failure from ordinary shadow-refactor handoff blockers before any bridge extraction work resumes.

FP-021 answers one question:

> Why did `forgepilot_start_opencode_worker` start a worker while ForgePilot status tools reported OpenCode execution disabled?

## Triggering Evidence

SHADOW-REF-008 observed:

```text
worker_id: WORKER-20260702T121741820Z-e60730d6
packet_id: FP-MCP-036
model_id: deepseek-v4-pro-high
target_workspace_id: forgepilot-chatgpt-mcp
status: FAILED
terminal_state: TERMINAL_FAILED
```

The worker start occurred even though status/disable tools reported:

```text
opencodeExecutionEnabled: false
executionAllowedNow: false
EXECUTION_DISABLED_GLOBAL
```

## Finding Split

SHADOW-REF-008 contained two findings that must not be collapsed:

```text
Finding 1: SHADOW-REF packet id rejected by OpenCode request validator.
Disposition: VALIDATION_NAMESPACE_BUG
Severity: workflow blocker / low execution risk

Finding 2: worker start tool spawned OpenCode despite disabled execution state.
Disposition: SAFETY_GATE_FAILURE
Severity: security-relevant execution-gate defect
```

## Required Investigation

FP-021 must determine:

1. Whether the worker start implementation calls the disable switch before spawning OpenCode.
2. Whether the worker start implementation validates request artifacts or packet ids before spawning OpenCode.
3. Whether the worker start implementation enforces model/run-mode allowlists before spawning OpenCode.
4. Whether the observed issue is limited to `FP-MCP-036` or broader.
5. What regression test or gate must exist before executor-driven implementation can resume.

## Safety Requirements

This packet must not start another worker, modify bridge source, clear execution disables, restart services, or perform bridge extraction.

## Non-Goals

This packet does not fix the bridge, implement the regression test, or resume extraction. It records the failure and defines the minimum next fix requirement.

## Acceptance Criteria

1. Root cause is stated from source evidence.
2. Blast radius is stated from source evidence plus observed worker telemetry.
3. `SAFETY_GATE_FAILURE` disposition is recorded.
4. Required regression behavior is defined.
5. Extraction remains blocked until a later fix packet proves disabled-state blocking.
6. ForgePilot and bridge working trees are clean after evidence is committed.
