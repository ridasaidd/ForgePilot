# FP-013 — Packet Report Summary View v1

## Task

Implement a first read-only ForgePilot packet report summary view.

## Goal

Make packet state inspectable without manually reading raw packet and run artifacts, while obeying `docs/reporting-evidence-rules.md`.

FP-013 answers one question:

> What committed packet/run evidence exists for this packet, and what may be safely claimed from it?

## Scope

Add a core ForgePilot reporting module and CLI command.

Recommended command:

```text
pnpm fp -- packet-report --packet-id <PACKET_ID> --json
```

The report should read repo-local committed artifacts and, where available, read-only persisted worker telemetry observations.

## Required Output Semantics

The report must distinguish at minimum:

- packet intent recorded,
- run artifacts present,
- verification artifacts present,
- direct MCP/operational proof artifacts present,
- worker telemetry observations present,
- whether observations are admitted or not evaluated,
- caveats / prohibited inference boundary.

## Required Boundary

The report must not admit evidence, rank models, route work, infer quality, or treat telemetry observations as admitted evidence.

Any telemetry observation must be labeled:

```text
Observation only. Not admitted evidence. Not routing input.
```

## Safety Requirements

This packet must not:

- create SQLite schema,
- mutate database records,
- admit evidence,
- compare models,
- score packets,
- rank models,
- add MCP tools,
- change bridge code,
- inspect live OpenCode workers.

## Non-Goals

This packet does not implement:

- dashboard UI,
- MCP report tool,
- full V1 report generator,
- admission/comparison reconstruction,
- routing policy,
- model scoring,
- automatic checklist update.

## Acceptance Criteria

1. A report module exists.
2. CLI supports `packet-report` / `--packet-report` with `--packet-id`.
3. JSON output is supported.
4. Text output is supported.
5. Missing packet fails clearly.
6. Existing packet reports packet file, title, run artifact paths, labels, and caveats.
7. Worker telemetry observations are included only as observations when available.
8. Report output includes the observation-only boundary.
9. Tests cover core report behavior.
10. Typecheck and test suite pass.
11. Evidence is recorded under `runs/FP-013/`.
12. Final git status is clean.

## Verification Requirements

Run at minimum:

```text
pnpm typecheck
pnpm test
pnpm fp -- packet-report --packet-id FP-MCP-157 --json
pnpm fp -- packet-report --packet-id FP-MCP-157
```

## Expected Result

ForgePilot gains its first core read-only reporting surface for single-packet evidence inspection.
