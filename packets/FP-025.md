# FP-025 — Scoped Executor Enablement Policy

## Task

Define the policy required before OpenCode execution may be enabled for the first real executor-driven bridge extraction.

## Goal

Prevent execution enablement from becoming a global, open-ended switch flip. Define packet-scoped authorization, model/task trust boundaries, time-boxing, and abort requirements before any real executor run is allowed.

FP-025 answers one question:

> What must be true before ForgePilot may enable OpenCode execution for FP-024's first bridge extraction retry?

## Current State

FP-024 proved the fixed worker-start gate correctly blocks execution while the global execution policy is disabled.

Current policy remains:

```text
opencodeExecutionEnabled: false
globalDisableActive: true
executionAllowedNow: false
effectiveDisableReason: EXECUTION_DISABLED_GLOBAL
```

## Core Rule

OpenCode execution must not be enabled globally merely to let FP-024 proceed.

Execution enablement must be:

```text
packet-scoped
target-workspace-scoped
model-scoped
run-mode-scoped
time-boxed
human-approved
abortable
observable
reversible
```

## Authorized Scope Shape

The first permitted execution window, if later implemented, must be limited to:

```text
packetId: FP-024
workspace: forgepilot-chatgpt-mcp
branch: feature/oauth-auth0
base commit: 3cd682c
model: deepseek-v4-pro-high
run mode: DESIGN_ONLY
task class: low-risk shadow extraction
prompt artifact: runs/FP-024/executor-prompts/first-shadow-extraction.md
source baseline: SHADOW-REF-006 server.ts hash 8412f3a74973a4ca6740a89581e0ea9476f5d01d35f5207f3193ebfee825ba1e
tool-contract baseline: FP-022 expanded 38-tool surface
```

Any deviation from this scope must fail closed.

## Model Trust Requirement

DeepSeek V4 Pro High may be considered only for this narrow task class:

```text
scoped low-risk ForgePilot bridge shadow extraction under explicit acceptance checks
```

This must not be treated as global trust for arbitrary bridge changes, security-sensitive code, execution-gate changes, OAuth/Auth0 changes, terminal-command changes, or live entrypoint changes.

## Required Human Approval Evidence

Before execution can be enabled, ForgePilot must record explicit human approval evidence binding at least:

```text
packetId
requestId or worker attempt id
modelId
runMode
workspace
branch
base commit
prompt artifact path
expiration timestamp
operator id
exact approved action text
```

Approval must be consumed or marked used before execution start, without mutating the original approval evidence.

## Time Box

Execution enablement must expire automatically.

Minimum acceptable policy:

```text
enable only for a single packet-scoped start attempt
```

Preferred policy:

```text
enable for FP-024 only, for one worker start, expiring within a short operator-approved window
```

## Abort Requirement

Execution must not be enabled until an abort path exists and is verified.

The bridge currently has no registered MCP tool matching:

```text
stop worker
cancel worker
abort worker
kill worker
terminate worker
```

Therefore FP-025 does not authorize execution yet.

A later packet must implement and verify an abort primitive proving:

```text
running worker can be identified
abort request is packet/worker scoped
abort refuses unknown or completed workers
abort sends bounded termination signal
worker status becomes terminal
stdout/stderr/status artifacts are preserved
abort action is recorded as evidence
abort cannot target arbitrary processes outside the worker record
```

## Enablement Preconditions

A future enable packet may proceed only after:

1. Abort primitive exists and is verified.
2. Human approval evidence contract exists for the exact run.
3. Enablement scope is packet/workspace/model/run-mode/time limited.
4. Disable switch remains fail-closed by default.
5. FP-024 prompt artifact is committed.
6. Bridge tree is clean at approved base commit.
7. Tool-contract baseline uses FP-022's expanded 38-tool parser.
8. Source baseline references SHADOW-REF-006 server.ts hash.
9. Start path records worker lifecycle evidence.
10. Failure dispositions include SAFETY_GATE_FAILURE, EXECUTION_POLICY_BLOCKED, REJECTED_EXTRACTION_ATTEMPT, and QUARANTINED_EXTRACTION_ATTEMPT.

## Non-Goals

This packet does not enable execution, start OpenCode, implement the abort tool, retry FP-024, change bridge source, or relax the global disable switch.

## Acceptance Criteria

1. Policy forbids unscoped global enablement.
2. Policy defines packet-scoped/time-boxed enablement requirements.
3. Policy defines DeepSeek task-class-scoped authorization.
4. Policy defines human approval evidence requirements.
5. Policy identifies missing abort path as a blocker.
6. Execution remains disabled after this packet.
7. ForgePilot and bridge working trees are clean after evidence is committed.
