# FP-033 — Bootstrap Canary Namespace Reconciliation

## Task

Reconcile the namespace blocker found in FP-032.

## Goal

Decide whether the first executor bootstrap canary should continue as `FP-031` or move to an MCP bridge namespace accepted by the remote runner.

## Finding

The packet namespace taxonomy says `FP-MCP-*` is for MCP bridge, tools, actions, and server integration work.

The selected FP-031 candidate changes the MCP bridge repository by adding:

```text
docs/executor-bootstrap-canary.md
```

Therefore the actual executor bootstrap attempt is a bridge/instrument-project packet, not a core ForgePilot product packet.

## Decision

Use a new namespace-correct packet for the actual bootstrap canary:

```text
FP-MCP-159 — Executor Bootstrap Documentation Canary
```

Keep FP-031 as admitted evidence of candidate selection and the namespace blocker.

Do not rename or mutate FP-031 history.

## Reason

The remote runner accepts `FP-MCP-*` request artifacts and rejects `FP-*` artifacts.

That behavior is compatible with the taxonomy for this specific canary because the primary changed artifact is in the MCP bridge repository.

## Boundary

No execution is enabled here.
No worker is started here.
No bridge source is changed here.
