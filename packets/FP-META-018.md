# FP-META-018 — Evidence Boundary Doctrine

## Task

Document ForgePilot's evidence boundary doctrine.

## Goal

Make explicit what counts as discussion, implementation, verification evidence, operational proof, admission, and completion.

## Scope

Add:

```text
docs/evidence-boundary-doctrine.md
```

The doctrine should preserve the core rule:

```text
Discussion is not evidence.
Implementation is not evidence by itself.
Verification is not admission.
Observation is not routing input.
Completion requires committed evidence.
```

## Non-Goals

- No admission implementation.
- No scoring.
- No routing.
- No schema change.
- No MCP tools.
