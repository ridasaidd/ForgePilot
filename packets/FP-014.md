# FP-014 — Project Summary Report v1

## Task

Implement a first read-only ForgePilot project summary report.

## Goal

Make ForgePilot V1/project state inspectable from committed checklist, packet inventory, and rule documents without manually reading many files.

FP-014 answers one question:

> What does the repository currently say about ForgePilot project/V1 state?

## Scope

Add a core project reporting module and CLI command.

Recommended command:

```text
pnpm fp -- project-report --json
pnpm fp -- project-report
```

The report should read repo-local files only.

## Required Output Semantics

The report must include at minimum:

- current report boundary,
- V1 completion definition if present,
- checklist capability status counts,
- checklist capability entries,
- packet inventory by namespace,
- recent packet files,
- governing docs references,
- next recommended namespace guidance if present,
- V1 completion status as `NOT_COMPLETE` unless every required capability is complete.

## Required Boundary

The report must include:

```text
This project report is an index over committed evidence and checklist state. It is not evidence by itself.
```

## Safety Requirements

This packet must not create SQLite schema, mutate database records, admit evidence, compare models, score packets, rank models, route work, add MCP tools, change bridge code, or rename historical packets.

## Non-Goals

This packet does not implement dashboard UI, MCP report tool, packet archive index, automatic checklist update, refactor eligibility engine, or admission/comparison reconstruction.

## Acceptance Criteria

1. A project report module exists.
2. CLI supports `project-report` / `--project-report`.
3. JSON output is supported.
4. Text output is supported.
5. Report includes checklist status counts.
6. Report includes packet inventory by namespace.
7. Report includes V1 completion status without overclaiming completion.
8. Report includes governing docs references.
9. Tests cover core project report behavior.
10. Typecheck and test suite pass.
11. Evidence is recorded under `runs/FP-014/`.
12. Final git status is clean.

## Verification Requirements

Run at minimum:

```text
pnpm typecheck
pnpm test
pnpm fp -- project-report --json
pnpm fp -- project-report
```

## Expected Result

ForgePilot gains a first project-wide reporting surface while preserving evidence boundaries.
