# FP-OPS-002 — Session Bootstrap Runbook

## Task

Create a repo-tracked runbook for starting a new ForgePilot session safely.

## Goal

Reduce dependence on private chat memory by giving future sessions a durable bootstrap procedure.

## Scope

Add:

```text
docs/session-bootstrap.md
```

The runbook should instruct future sessions to check git state, read the progress checklist, read the packet namespace taxonomy, respect evidence boundaries, and confirm manual OpenAI Actions refresh when MCP tools change.

## Non-Goals

- No implementation code.
- No automation.
- No MCP tools.
- No background work.
