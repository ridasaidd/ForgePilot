# FP-026 — OpenCode Worker Abort Primitive

## Task

Implement and verify a packet/worker-scoped abort primitive for OpenCode workers.

## Goal

Ensure ForgePilot can stop a recorded running OpenCode worker safely and preserve abort evidence before any execution enablement is considered.

FP-026 answers one question:

> Can ForgePilot abort a recorded running worker without allowing arbitrary process termination or losing worker lifecycle evidence?

## Triggering Evidence

FP-025 found:

```text
NO_REGISTERED_WORKER_ABORT_TOOL_FOUND
```

FP-025 therefore blocked OpenCode execution enablement until a worker abort primitive exists and is verified.

## Required Behavior

The abort primitive must:

```text
require exact approval text
be scoped to packetId + workerId
read an existing worker status artifact
refuse unknown workers
refuse completed/non-running workers
refuse records that are not OpenCode worker records
refuse records whose paths do not match the expected worker directory
send a bounded termination signal only to the recorded worker process/group
transition status to ABORTED
record abort reasons and timestamps
preserve stdout/stderr/start-request/status artifacts
not delete or roll back workspace files
```

## Scope Boundary: Partial Work

FP-026 does not solve rollback of partial workspace changes.

For FP-024's first extraction, the run mode remains `DESIGN_ONLY`; an aborted worker may leave partial workspace changes if execution has reached file-writing behavior in a future run.

The abort primitive must preserve evidence and stop the worker. A future extraction acceptance packet must decide whether partial workspace changes are reverted, quarantined, or reviewed before admission.

## Required Successful Abort Definition

A successful abort requires:

```text
worker status changes from RUNNING to ABORTED
completedAt is set
abortedAt is set
abortRequestedAt is set
SIGTERM or equivalent bounded signal is recorded
status artifact is rewritten with abort evidence
stdout/stderr/start-request paths remain present in the status record
abort action cannot target arbitrary processes outside the worker record
```

## Non-Goals

This packet does not enable execution, start OpenCode, retry FP-024, perform bridge extraction, restart the MCP service, or implement rollback of partial workspace changes.

## Acceptance Criteria

1. Bridge source exposes a registered `forgepilot_abort_opencode_worker` tool.
2. Abort refuses unknown workers.
3. Abort refuses completed workers.
4. Abort refuses malformed/non-OpenCode worker records.
5. Abort terminates a recorded running worker and marks status `ABORTED`.
6. Abort evidence preserves status/start-request/stdout/stderr artifacts.
7. `pnpm build` passes.
8. `pnpm test` passes.
9. Bridge source changes are committed.
10. ForgePilot records evidence through the V1-O canonical path.
