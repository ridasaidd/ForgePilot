# FP-028 — Execution Enablement Boundary Flag Source Inspection

## Task

Inspect the MCP bridge source for the boundary/status flags surfaced before FP-027 canary execution.

## Goal

Prevent scoped enablement from being designed around assumed semantics.

FP-028 answers one question:

> What does the current bridge source actually require for the enablement/status flags that block FP-027?

## Flags Inspected

```text
contractComplete
opencodeBoundarySatisfied
secretBoundarySatisfied
networkBoundarySatisfied
humanApprovalRecorded
```

## Required Answer Shape

For each flag FP-028 must answer:

```text
1. what condition makes it true
2. current actual value and why
3. whether it can be made true by legitimate scoped configuration
4. whether it can become true too easily without the protection it implies
```

## Scope

Source inspection only.

No bridge source changes. No execution enablement. No worker start. No FP-027 canary retry.

## Acceptance Criteria

1. Source locations are identified.
2. Every flag has a falsifiable condition.
3. Surface mismatches are named explicitly.
4. Human approval artifact semantics are mapped to the existing tools.
5. Follow-up requirement for scoped enablement is stated separately.
