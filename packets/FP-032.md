# FP-032 — Remote Runner Packet Namespace Compatibility Inspection

## Task

Inspect and record the packet namespace mismatch blocking FP-031 executor bootstrap.

## Goal

Determine whether FP-031 is blocked because of local request validity, artifact shape, or remote runner packet namespace policy.

## Scope

Inspection and evidence only.

No bridge source changes. No runner source changes. No execution enablement. No worker start. No remote start endpoint call.

## Observed Problem

FP-031 request artifact was locally valid and locally eligible for remote-runner handoff, but the remote runner validate-request endpoint rejected it with:

```text
INVALID_PACKET_ID
RUNNER_REJECTED_REQUEST
```

## Inspection Method

Compare non-starting endpoint validation for:

```text
FP-031 / REQ-20260702T141753581Z-650bc292
FP-MCP-036 / REQ-20260622T144553300Z-fbbe8d82
```

Both checks use the validate-request endpoint only and do not start execution.

## Acceptance Criteria

1. Local validator result for FP-031 is recorded.
2. Remote endpoint result for FP-031 is recorded.
3. Remote endpoint result for a known FP-MCP request is recorded.
4. The blocker is classified without starting a worker.
5. Follow-up is separated from implementation.
